## A. 文风特征速查（迁移目标）

| 维度 | 水球泡特征 |
|---|---|
| 姿态 | 平视真诚，不端导师；"同学"称呼拉平等 |
| 结构 | 反直觉开头 → 个人经历 → 编号结论 → 反思 → 互动收尾 |
| 句式 | 强判断短句；"不是A而是B"；句均≤25字 |
| 金句 | 每3-5句一个可截屏句 |
| 收尾 | 提问式交回用户，不喊口号 |
| 标签 | #认知提升 #独立思考 #深度思考 #搞钱 #AI |

## B. 改写示范（用户原稿 → 水球泡风，保留事实）

### 示范 1：反直觉开头 + 不换人设（第1集）
**原稿事实**：给自己打工两年、大二下开始、3网站1小程序、8000+粉、AI agent 当员工
**改写要点**：
- 开头："很多人问我，一个人到底能不能开公司？我的答案是：能。但原因和你想的，完全相反。"
- 反直觉："不是因为你什么都能干，而是因为你有 AI。"
- 暴露不足："但我也得诚实说，我现在这套体系还没完全搭起来。很多活还是从零开始干，真的挺痛苦。"
- 互动："你对一人公司这事怎么看？评论区聊聊。"

### 示范 2：编号式核心结论（第3集）
**原稿事实**：第一个网站、有人付费、现金流/资质/通道问题、学校没教
**改写要点**：
- 编号结论："我现在的理解：**内容、产品、商业化，是三件完全不同的事。**"
- 推进感："很多做内容的，卡在产品这步。很多做出产品的，卡在商业化这步。我现在，正从第二步往第三步挪。"
- 金句："凡事发生，必有利于我。卡住了，就去解决。"
- 互动："你卡在哪一步了？"

### 示范 3：金句化 + 批判性（第5集）
**原稿事实**：AI 附和、训练逻辑让你满意、幻觉未解、提示词"请质疑我"
**改写要点**：
- 钩子："你们有没有发现，AI 有个特别隐蔽的坑：它会附和你。"
- 机制解释："因为它的训练逻辑，本质上就是尽量让你满意。它不倾向于反驳你。"
- 方法："我现在用 AI 之前，先喂它一句：**请质疑我的方案，站在对立面。**"
- 金句："工具是放大镜。放大你的能力，也放大你的错误。"

### 示范 4：引用经典 + 真诚暴露（第9集）
**原稿事实**：发布后难熬一周、庄子引文、外部肯定少、正向反馈驱动
**改写要点**：
- 场景共鸣："你有没有过这种阶段：事推出来了，反馈还没来。你只能原地等。"
- 经典白话说："《庄子》里一句话我特别喜欢：**举世誉之而不加劝，举世非之而不加沮。**"
- 反套路："真让我一直做下去的，不是毅力，是一种正向反馈……"
- 金句："**毅力是靠不住的。靠得住的，是这件事能反过来给你能量。**"

## C. 蒸馏报告结构示范（阶段一产出骨架）

见 `distillation-framework.md` 7 维度。水球泡实例的 7 维标题：
1. 人物档案（李泽同/且曼创始人/认知成长赛道）
2. 跨平台矩阵与数据（抖音33.8万→70万、爆款闲鱼84.8万赞）
3. 核心观点：一人公司身份切换 / 护城河三层 / AI卷技能死路 / 滑梯效应 / 规则三阶 / 热点解构 / 免费获客
4. 内容公式：热点×认知解构×搞钱落点；编号硬核结论；#认知提升 标签体系
5. 商业闭环：免费内容→且曼课程→品牌反哺
6. 可借鉴点表
7. 信息来源与局限（标注口径时间）

## D. DeepSeek 配置关键卡示范（阶段三产出）

兜底「一般讨论」卡公式（最重要）：
```
钩子(反直觉) → 个人经历("我观察到") → 编号观点(≤15字) → 反思("但我也得说") → 互动(提问) + 标签
```

正反例对比（成功 vs 失败）见 `deepseek-config-template.md` 模块4。
